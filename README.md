# MMReon

Личный трекер своих матчей Dota 2 с **точным изменением рейтинга** сразу после игры —
без ожидания статистики Dota Plus и без входа в Steam-аккаунт.

Как это работает:

1. Клиент Доты через официальный **Game State Integration** сообщает трекеру,
   что матч закончился: победа или поражение, герой, У/С/П, GPM/XPM.
2. После матча трекер раз в пару секунд проверяет окно Доты. Как только вы открываете
   **«Профиль → История»**, он узнаёт вкладку и читает с неё рейтинг и уверенность в ранге.
3. Разница с прошлым значением — это точное «ИР» за матч. Оно записывается в `data/matches.json`.

Трекер ничего не меняет в игре и не читает её память: он только принимает данные GSI
и смотрит на картинку окна, как программа для записи экрана.

## Установка (Windows)

1. **Python 3.10+** и зависимости:
   ```
   pip install -r requirements.txt
   ```
2. **Tesseract OCR** — движок распознавания цифр. Установщик для Windows:
   https://github.com/UB-Mannheim/tesseract/wiki — достаточно английского языка (по умолчанию).
   Если ставите в стандартную папку `C:\Program Files\Tesseract-OCR`, трекер найдёт его сам.
   Иначе укажите путь в `data/config.json` → `tesseract_cmd`.
3. **Конфиг GSI** в папку Доты:
   ```
   python tools/install_gsi.py
   ```
   Если Дота стоит в другой библиотеке Steam и не нашлась — передайте путь к библиотеке:
   `python tools/install_gsi.py "D:\SteamLibrary"`.
4. В Steam: **Dota 2 → Свойства → Параметры запуска** → добавьте `-gamestateintegration`.
5. В Доте: **Настройки → Видео → Режим отображения → «Оконный без рамки»**.
   В полноэкранном режиме Windows отдаёт программам чёрный кадр.

Поддерживаются разрешения 16:9 (проверено на 1920×1080), русский клиент.

## Запуск

Обычный запуск — **двойной клик по `MMReon.pyw`**: окно и виджет без консоли.
Сообщения трекера пишутся в `data/mmreon.log`.

Ярлык с иконкой MMReon:

```
python tools/make_shortcut.py             # на рабочем столе
python tools/make_shortcut.py --startup   # и в автозагрузке, чтобы запускался вместе с Windows
```

Для отладки — с консолью:

```
python run.py            # окно со сводкой и виджет
python run.py --no-ui    # только консоль
```

Окна:

- **Главное окно** — текущий рейтинг и медаль, итог сессии и недели, график за 30 дней,
  список матчей с точным ИР. Кнопкой «×2» в строке матча можно вручную отметить жетон
  двойного рейтинга (авто → да → нет). Обычное окно с тёмной рамкой: его можно
  растягивать и разворачивать; свёрнутый MMReon работает в фоне, крестик — выход.
  Иконки медалей и героев грузятся из интернета (OpenDota и Steam);
  без интернета вместо них показываются буквенные значки.
- **Виджет** — плашка с медалью, MMR, победами/поражениями и изменением за сессию.
  Виден, пока Дота открыта и вы в главном меню, прячется на время матча.
  Работает как оверлей: нет кнопки на панели задач и в Alt+Tab, не забирает фокус у игры.
  По умолчанию закреплён поверх панели профиля Доты — положение и размер считаются
  по окну игры, клики проходят сквозь виджет в Доту. Если снять галочку
  «Закрепить на панели профиля», виджет можно перетаскивать мышью, а двойной клик
  открывает главное окно. Прозрачность настраивается ползунком внизу главного окна
  (полупрозрачным становится весь виджет вместе с текстом).

Окна сделаны на pywebview (HTML/CSS в `mmreon/ui/`) и используют WebView2 —
он уже есть в Windows 10/11.

Порядок работы:

- при первом запуске откройте «Профиль → История» — трекер запомнит исходный рейтинг;
- после каждого матча снова откройте «Историю» — в консоли появится точное ИР.

Если между матчами «Историю» не открывать, трекер узнает только суммарное изменение
за несколько игр — по отдельным матчам его уже не разложить.

## Что ещё собирает трекер

- **Таблица «Истории».** Пока открыта вкладка «Профиль → История», трекер читает её строки:
  герой, результат, дата, длительность и тип игры (рейтинговая или Turbo).
  Так у записанных матчей появляется тип игры, а матчи, сыгранные без трекера или до его
  установки, добавляются в журнал — без точного изменения рейтинга.
- **Предметы и таланты.** Из GSI записываются сборка в конце матча, рюкзак, нейтральный
  предмет, Аганим и Шард, таланты, время появления каждого предмета и добивания к 10:00.
  Подробности открываются кликом по имени героя в списке матчей.
- **Герои.** Матчи, винрейт и суммарное изменение рейтинга на каждом герое.
- **Прогноз.** Сколько примерно побед нужно до следующей звезды и медали — по средней
  победе без жетона.

Для предметов в конфиг GSI добавлен раздел `items`. Уже установленный конфиг MMReon
обновляет сам при запуске; после этого Доту нужно перезапустить один раз.

## Проверка распознавания

```
python tools/test_ocr.py screenshot.png   # на сохранённом скриншоте
python tools/test_ocr.py --live           # снимет окно Доты через 5 секунд
```

`--live` сохраняет кадр в `data/debug/` — пригодится, если цифра не читается.

## Данные

Всё хранится локально в папке `data/` (в репозиторий не попадает):

- `config.json` — порт и токен GSI, путь к Tesseract, интервал проверки экрана;
- `matches.json` — матчи и последний прочитанный рейтинг.

Статусы матча: `pending` — ждёт открытия «Истории», `exact` — точное ИР,
`unrated` — рейтинг не изменился (турбо или обычная игра), `group` — несколько матчей
без промежуточного чтения, известна только сумма, `history` — матч взят из таблицы
«Истории». Поле `mode` — тип игры из «Истории» (`ranked`, `turbo`, `other`).
Поле `double` — изменение примерно вдвое больше обычного, похоже на жетон двойного рейтинга.
